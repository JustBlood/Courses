# Паттерны системы (backend)

## Назначение
Фиксация архитектурных и кодовых паттернов backend, чтобы агент принимал однообразные решения во всех задачах.

## Базовые паттерны (черновик)
- Архитектурный стиль: модульный backend на Java (Spring Boot).
- Слои: `controller -> service -> repository -> model`.
- DTO/маппинг: использовать отдельные DTO и мапперы, не отдавать entity напрямую.
- Ошибки и валидация: централизованная обработка через global exception handler.
- Миграции БД: только через версионируемые скрипты в `db/migration`.

## Принципы изменений
- Минимальные инвазивные изменения (не рефакторить лишнее вне рамок задачи).
- Сначала анализ влияния по слоям и зависимостям.
- Сохранение обратной совместимости API, если иное не согласовано в PRD.
