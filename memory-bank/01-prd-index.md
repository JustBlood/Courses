# Разводящий PRD-документ (индекс)

## Назначение
Этот файл — единая точка входа в PRD. Он ссылается на главы PRD, которые можно читать выборочно, чтобы не перегружать контекст.

## Главы PRD
- [PRD-00: Обзор и цели](./prd/00-overview-and-goals.md)
- [PRD-01: Пользовательские сценарии](./prd/01-user-scenarios.md)
- [PRD-02: Функциональные требования](./prd/02-functional-requirements.md)
- [PRD-03: Нефункциональные требования](./prd/03-non-functional-requirements.md)

- [PRD-05: Критерии приемки](./prd/05-acceptance-criteria.md)

## Правило чтения
1. Сначала читать этот индекс.
2. Затем переходить только в релевантные главы под конкретную задачу.
3. После анализа обновлять [02-active-context.md](./02-active-context.md).
