# Технический контекст

## Текущий стек (по репозиторию)
- Язык: Java
- Сборка: Maven (`pom.xml`, мульти-модульный репозиторий)
- Основной сервис: `monolith-mvp`
- Дополнительный сервис: `media-service` (исключается из анализа по умолчанию через `.clineignore`)

## Backend-ориентиры
- Предположительно Spring Boot / Spring Security / Spring Data JPA
- Миграции БД: `monolith-mvp/src/main/resources/db/migration`

## Хранилища и данные
- Локальные данные и вложения в `data/` (в анализ не включать по умолчанию)
- Файлы БД и артефакты окружения исключать из автоконтекста

## Интеграции и инфраструктура
- Docker Compose файлы в корне
- Возможные внешние интеграции фиксировать по мере появления в PRD-главах
