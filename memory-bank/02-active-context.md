# Активный контекст

## Текущая цель
Организовать устойчивый workflow работы с Cline + `gpt-5.3-codex` в данном репозитории без перегруза контекста.

## Что нужно сделать по текущей meta-задаче
- Построить каркас `memory-bank`.
- Настроить `.clinerules` для обязательного чтения контекста и правил обновления документов.
- Настроить `.clineignore` для исключения шумных и нерелевантных файлов/директорий.

## Источники требований для этой задачи
- [00-project-brief.md](./00-project-brief.md)
- [01-prd-index.md](./01-prd-index.md)
- Комментарии пользователя в чате (текущий task).

## Решения в рамках текущей задачи
- Использовать markdown-структуру с перекрестными ссылками.
- PRD разбивать по главам (`memory-bank/prd/*`).
- Вести два типа прогресса:
  - прогресс выполнения текущей задачи;
  - общий прогресс разработки системы.

## Что обновлять после завершения анализа задачи
- Уточнить границы конкретной задачи.
- Зафиксировать выбранный план реализации.
- Обновить ссылочный маршрут по PRD-главам, которые реально использовались.
