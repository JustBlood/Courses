# Memory Bank Workflow

## Обязательное чтение в начале каждой задачи
1. все файлы из `.clinerules`
2. `memory-bank/00-project-brief.md`
3. `memory-bank/pre-tasks.json`
4. `memory-bank/tasks.json`
5. `memory-bank/01-prd-index.md`
6. Только релевантные главы из `memory-bank/prd/*` под текущую задачу по ссылкам из `memory-bank/01-prd-index.md` на основании контекста задачи
7. Чтение файлов из `memory-bank/pre-task-artifacts` не нужно без явной неоюходимости анализа артефактов предыдущих задач.
8. Чтение файла `memoty-bank/05-task-execution-progress.md` не требуется в рамках задачи без явного указания.

## Обязательные обновления
- После анализа задачи обновлять `memory-bank/02-active-context.md`.
- По завершении задачи **или когда контекст уже заполнен на > 300.000** обновлять `memory-bank/05-task-execution-progress.md`.
- После ПОЛНОГО завершения задачи обновлять `memory-bank/06-system-development-progress.md`.
- Если задача атомарна и сформирован отдельный артефакт под неё - следует скомпрессировать `memory-bank/05-task-execution-progress.md` до файла-индекса со ссылками на артефакты по результатам задач. Если отдельного артефакта нет - не трогать записанный контекст
- В конце своей работы - если файл `memory-bank/05-task-execution-progress.md` был прочитан и найденные в нем задачи прямо не относятся к выполняемой, а количество строк в файле > 300, то следует либо вставить ссылку на артефакт задачи, если он есть, либо удалить ранее сохраненный и уже неактуальный контекст такой задачи (не относящийся к выполняемой) из файла. 
- Полная очистка файла `memory-bank/05-task-execution-progress.md` запрещена 

## Для длинных задач
1. Зафиксировать промежуточный контекст в `05-task-execution-progress.md`.
2. Если задача не была выполнена за 1 итерацию - зафиксировать активный контекст в `02-active-context.md`.
3. Продолжать работу через новую задачу (`/newtask`) с загрузкой этих документов.
