# Memory Bank Workflow

## Token Budget Gate (обязательно)
- После КАЖДОГО действия (tool call / шаг размышления или написания кода) агент обязан:
    1. Проверить текущее значение Context Window Usage.
    2. Если usage > 350000 токенов:
        - немедленно приостановить реализацию;
        - записать текущий контекст во всех подробностях в  `memory-bank/02-active-context.md`, чтобы при запуске новый агент смог полностью понимать выполняемую задачу, какие файлы ему необходимо проанализировать;
        - завершить итерацию сообщением "требуется /newtask для продолжения".
- Запрещено продолжать выполнение без этой фиксации при превышении лимита.

## Обязательное чтение в начале каждой задачи
1. все файлы из `.clinerules` с применением ВСЕХ перечисленных там файлов
2. `memory-bank/00-project-brief.md`
3. `memory-bank/02-active-context.md`
4. `memory-bank/tasks.json`
5. `memory-bank/01-prd-index.md`
6. Только релевантные главы из `memory-bank/prd/*` под текущую задачу по ссылкам из `memory-bank/01-prd-index.md` на основании контекста задачи (`memory-bank/02-active-context.md`)
7. Чтение файлов из `memory-bank/pre-task-artifacts` не нужно без явной необходимости анализа артефактов предыдущих задач.
8. Чтение файла `memory-bank/05-task-execution-progress.md`

## Обязательные требования к обновлению файлов
- После анализа задачи ты должен обновлять `memory-bank/02-active-context.md`.
- По ПОЛНОМУ завершению задачи ты должен весь активный контекст из файла `memory-bank/02-active-context.md` копировать в файл-артефакт по выполнненной задаче в директорию `memory-bank/task-artifacts` и обязательно добавить ссылку на артефакт в файл `memory-bank/05-task-execution-progress.md`.
- После ПОЛНОГО завершения задачи обновлять `memory-bank/06-system-development-progress.md`, если задача содержала архитектурно важные изменения.
- Полная очистка и редактирование предыдущих задач в файле `memory-bank/05-task-execution-progress.md` запрещена
- После ПОЛНОГО выполнения задачи, создания артефакта по ней и добавления его в файл-индекс `memory-bank/05-task-execution-progress.md`, требуется очистить файл `memory-bank/02-active-context.md`

## Для длинных задач
1. Зафиксировать промежуточный контекст в `memory-bank/02-active-context.md`.
2. Продолжать работу через новую задачу (`/newtask`) с загрузкой этих документов.
