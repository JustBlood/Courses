# Memory Bank Workflow

## Обязательное чтение в начале каждой задачи
1. все файлы из `.clinerules`
2. `memory-bank/00-project-brief.md`
3. `memory-bank/pre-tasks.json`
4. `memory-bank/tasks.json`
5. `memory-bank/01-prd-index.md`
6. Только релевантные главы из `memory-bank/prd/*` под текущую задачу по ссылкам из `memory-bank/01-prd-index.md` на основании контекста задачи

## Обязательные обновления
- После анализа задачи обновлять `memory-bank/02-active-context.md`.
- По завершении задачи **или перед исчерпанием контекста** обновлять `memory-bank/05-task-execution-progress.md`.
- После ПОЛНОГО завершения задачи обновлять `memory-bank/06-system-development-progress.md`.

## Для длинных задач
1. Зафиксировать промежуточный контекст в `05-task-execution-progress.md`.
2. Зафиксировать активный контекст в `02-active-context.md`.
3. Продолжать работу через новую задачу (`/newtask`) с загрузкой этих документов.
