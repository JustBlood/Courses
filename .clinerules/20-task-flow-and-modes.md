# Task Flow and Modes

## Что такое задача
Задача — это атомарное изменение или доработка разрабатываемой системы. Ограничена по цели, критериям, изменениям.

## Целевой флоу выполнения задач
1. Прочитать обязательные документы из `10-memory-bank-workflow.md`.
2. Выбрать задачу из `memory-bank/pre-tasks.json` или из `memory-bank/tasks.json`, если все задачи из `memory-bank/pre-tasks.json` уже выполнены. 
3. Выполнять задачу по гайдалайну из секции agent_instructions файлов `memory-bank/pre-tasks.json` или `memory-bank/tasks.json`, в зависимости от места взятия задачи.
4. Если требуется - выбрать субагента для анализа необходимых пунктов PRD и задачи из переданного пользователем тикета.
5. Зафиксировать рамки задачи, критерии готовности и риски. Если используется субагент - передать эту задачу ему.
6. Сформировать план работ. Если используется субагент - получить его анализ и на его основании сформировать план работ.
7. Выполнить реализацию/изменения после утверждения плана пользователем.
8. Обновить `memory-bank/05-task-execution-progress.md` (если задача содержит > 300.000 токенов контекста)
9. Обновить `02-active-context.md` в случае неполного завершения задачи в рамках итерации или если текущий контекст вышел за лимит 300.000. В файл 
10. После ПОЛНОГО завершения — обновить `06-system-development-progress.md` и очистить `02-active-context.md`.

## Работа по режимам
- **PLAN MODE**: анализ, декомпозиция, уточнение границ, без изменений кода.
- **ACT MODE**: внесение изменений, валидация, фиксация прогресса.

## Анализ задачи
1. Прочитать обязательный контекст memory-bank.
2. Определить релевантные PRD-главы.
3. Сформировать план реализации.
4. При широком ресерче использовать субагентов.
5. Зафиксировать выводы в `02-active-context.md`.

## Обязательные элементы, которые требуется продумать перед реализацией
- Цель и ожидаемый результат.
- Границы (что входит / не входит).
- Источник требований (PRD/комментарии).
- Критерии готовности и проверки.
- Риски и зависимости.

## Правило для длинных задач
- Если контекст более 300.000 токенов на текущий момент:
  1. Обновить `05-task-execution-progress.md`.
  2. Обновить `02-active-context.md`.
  3. Продолжить через `/newtask` с загрузкой этих документов.
