# Task Flow and Modes

## Целевой флоу выполнения задач
1. Прочитать обязательные документы из `10-memory-bank-workflow.md`.
2. Прочитать релевантные требования задачи (PRD/комментарии/тикет).
3. Зафиксировать рамки задачи, критерии готовности и риски.
4. При широком исследовании — выбрать и запустить субагентов.
5. Сформировать план работ.
6. Выполнить реализацию/изменения.
7. Обновить `memory-bank/05-task-execution-progress.md` (если задача длинная) и `02-active-context.md`.
8. После полного завершения — обновить `06-system-development-progress.md`.

## Работа по режимам
- **PLAN MODE**: анализ, декомпозиция, уточнение границ, без изменений кода.
- **ACT MODE**: внесение изменений, валидация, фиксация прогресса.

## Правило для длинных задач
- Если контекст растёт и есть риск упора в лимит:
  1. Обновить `05-task-execution-progress.md`.
  2. Обновить `02-active-context.md`.
  3. Продолжить через `/newtask` с загрузкой этих документов.
