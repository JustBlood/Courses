# Subagents Guidelines

## Правило выбора исполнителя
- Для широкого исследования: субагенты (read-only).
- Для реализации изменений: основной агент в ACT MODE.

## Когда использовать субагентов
- Когда требуется широкое исследование нескольких подсистем.
- Когда требуется самостоятельно продумать реализацию задачи.
- Когда последовательное чтение большого объёма файлов перегружает контекст.
- Для предварительного ресерча перед правками.

## Правила запуска
- Выбирать использование субагентов самостоятельно по выполняемой задаче.
- Формулировать для каждого субагента узкий исследовательский вопрос.
- Обязательно добавлять в промпт вызываемого субагента его настройку, взятую из `memory-bank/subagents/*`. Выбор промпта зависит от типа задачи, которую необходимо выполнить.
- Начальный промпт для субагента генерировать самостоятельно на основе контекста переданного пользователем / полученного в результате выполнения задачи / полученного от других субагентов. 
- Возвращать в основной поток краткий синтез результатов без искажений важнейших выводов и ссылки на файлы.

## Ограничения и безопасность
- Учитывать, что субагенты read-only и не заменяют реализацию.
- Не запускать субагентов для маленьких локальных задач, где overhead выше пользы.
