# Subagents Guidelines

## Местонахождение субагентов
Все субагенты находятся в `memory-bank/subagents`

## Правило выбора исполнителя
- Для проработки архитектуры и проектирования системы: `memory-bank/subagents/system-architect.md`
- Для проработки архитектуры и проектирования backend: `memory-bank/subagents/backend-architect.md`
- Для приоритезации, оценки и организации задач: `memory-bank/subagents/sprint-prioritizer.md`
- Для реализации изменений: основной агент в ACT MODE.

## Когда использовать субагентов
- Когда требуется исследование перед выполнением задачи.
- Когда требуется самостоятельно продумать реализацию задачи.
- Когда последовательное чтение большого объёма файлов перегружает контекст.
- Для предварительного ресерча перед правками.

## Правила запуска
- Ты можешь запускать субагентов самостоятельно в любом своем вопросе и никак не ограничен в их использовании.
- Формулировать для каждого субагента узкий исследовательский вопрос.
- Обязательно перед начальным промптом субагента вставляй текст из `memory-bank/subagents/*` вызываемого субагента. 
- Основной промпт-запрос для субагента генерировать самостоятельно на основе контекста переданного пользователем / полученного в результате выполнения задачи / полученного от других субагентов. 
- Возвращать в основной поток краткий синтез результатов без искажений важнейших выводов и ссылки на файлы.

## Ограничения и безопасность
- Учитывать, что субагенты read-only и не заменяют реализацию.
- Не запускать субагентов для маленьких локальных задач, где overhead выше пользы.
