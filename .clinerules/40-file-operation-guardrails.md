# File Operation Guardrails

## Общие ограничения
- Не изменять файлы вне рамок задачи без явной необходимости.
- Не редактировать бинарные/медиаданные файлы.
- Не использовать массовые авто-рефакторинги по всему репозиторию без запроса.

## Предпочтения по безопасности
- Для потенциально рискованных изменений сначала делать анализ влияния.
- Конфиги и миграции изменять только при наличии явного требования.
- Для сомнительных правок предпочитать точечные изменения с явной проверкой результата.

## Работа с контекстно-шумными файлами
- Всё, что не нужно для анализа и реализации задачи, должно быть исключено через `.clineignore`.
- Вручную читать исключённые файлы только при прямой необходимости.
